# Magyarítások Macre

Windows-os játékmagyarítások átültetve macOS-re, a Feral Interactive Mac-es változataihoz. A fordításokat nem én készítettem: a fájlok bájtra azonosak az eredeti Windows-os telepítőkben lévőkkel, csak a telepítés módja készült újra Mac-re. A készítők nevét és feltételeit minden játék mappájában a `FELTETELEK.txt` tartalmazza.

| Játék | Magyarítás | Állapot |
| --- | --- | --- |
| [Life is Strange](life-is-strange/) | FileRise Fordítócsapat, 5.0 | valódi Macen kipróbálva, működik |
| [Alien: Isolation](alien-isolation/) | Patyek, Beholder, 1.2 | tesztkörnyezetben kipróbálva |

Letöltés: zöld **Code** gomb → **Download ZIP**. A telepítés lépései a játékok saját leírásában vannak.

A `tools/extract_clickteam.py` a Clickteam Install Creatorral készült Windows-os telepítőket csomagolja ki, futtatás nélkül.
